# Security

This repository holds the public website of La Vigilia, lavigilia.org.

If you find a security issue on the site, or data published in this repository by mistake (personal data, a secret, an internal document), please write to **contact@lavigilia.org**, describing what you saw and how to reproduce it. Please do not open a public issue for this kind of report. GitHub private vulnerability reporting (the "Security" tab of the repository) can be used as well.

We acknowledge receipt and tell you what we do about it. A fix takes the form of a new publication, visible in the history of this repository.

We read English, French and Italian.
